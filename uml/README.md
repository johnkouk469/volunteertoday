# UML models

The UML models of VolunteerToday, as files in the format of [StarUML](https://staruml.io/), and the diagrams exported from them.

| File | Contents |
|---|---|
| [`classdiagram.mdj`](classdiagram.mdj) | The class model: 9 packages, 43 classes and 2 enumerations, drawn in one class diagram. Documented in [4. Static model](../docs/static-model.md). |
| [`usecase_activity_diagrams.mdj`](usecase_activity_diagrams.mdj) | The use-case diagram (10 use cases) and 8 activity diagrams. Each activity diagram is contained as an extension of the corresponding use case of the use-case diagram. Documented in [2. Use cases](../docs/use-cases.md). |
| [`patterns/abstractfactory.mdj`](patterns/abstractfactory.mdj) | The class diagram of the Abstract Factory pattern (7 classes). |
| [`patterns/BridgePatternForDonations.mdj`](patterns/BridgePatternForDonations.mdj) | The class diagrams of the Bridge pattern for donations (10 classes). |

| Folder | Contents |
|---|---|
| [`diagrams/`](diagrams) | The use-case diagram and the eight activity diagrams as images. |
| [`diagrams/class-model/`](diagrams/class-model) | The class boxes, package diagrams and class diagrams of the static model as images. |
