# 3. UI mock-ups

Section 3 of the group's *User Requirements and System Specification* (version 2.0, 11 April 2021): sample windows of the user interface. The seventeen screens were designed in Figma and cover signing in and signing up, the home page, notifications and the user menu, the user, organisation and event pages, event creation, search, and the four ways to make a donation. The classes behind them are described in [4. Static model](static-model.md), and the scenarios that walk through them are in [2. Use cases](use-cases.md).

The pictures are the files in [`mockups/`](../mockups).
